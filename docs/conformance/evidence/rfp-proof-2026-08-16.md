## Canonical exact settlement and native automatic cataloging

Command:

```bash
pnpm --filter @autolayer/api evidence:testnet
```

The runner imports the stock `x402Client`/`x402HTTPClient` from `@x402/core@2.21.0` and `ExactStellarScheme` from `@x402/stellar@2.21.0`.
